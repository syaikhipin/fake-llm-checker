How to read the result

One question, five possible answers:

🟢 REAL MODEL
The model is genuine.

It behaved exactly like the official model on every probe.

🟡 MODEL UNVERIFIED
Can't confirm the model's identity.

Something sits between you and the provider, or the probes couldn't verify it. Whoever runs it sees all your traffic.

🟠 POSSIBLY MASKED
One suspicious signal.

Something doesn't look like the genuine model. Re-run to rule out a fluke before acting.

🔴 MASKED MODEL
You're not getting what you paid for.

Multiple independent signals: model substitution, a hijacked system prompt, or a fabricated API.

⚪ INCONCLUSIVE
No verdict possible.

Usually means the key was rejected — the probes never got to run. Check the key and try again.
